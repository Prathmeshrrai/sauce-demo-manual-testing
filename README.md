-- E-Commerce Application — Manual Testing Project
Overview
Manual test suite for a live e-commerce demo application (SauceDemo), 
covering core user flows: Login, Cart, Checkout, and Logout.

Scope
- 12 test cases across 4 modules
- Functional and negative testing (invalid credentials, empty required 
  fields, locked-out accounts, unauthorized page access after logout)
- Each test case documented with pre-conditions, steps, test data, 
  expected vs. actual results, and pass/fail status

Tools Used
- Manual testing methodology (STLC-based)
- Test case documentation in structured spreadsheet format

What I Learned
Practiced designing both happy-path and negative test scenarios, 
applying boundary and negative testing techniques, and documenting 
results in an industry-standard test case format.
